# Starrail  RogueDLCMap 棋盘数据 / 图册 / 生成动画


## 棋盘生成算法

按模板的 rule_id 升序逐条执行：

1. **特殊类型**（2 休整、4 战斗·虫群、5 精英、6 冒险、7 奖励、9 事件·虫群、11 首领、12 首领·虫群、13 交易）：从“未分配且候选含该类型”的格里取 `min(配额, 可用)` 个；配额来自 PoolA（多值表示截断档位）；类型 1 空白配额恒 0；类型 3/8 跳过这一步。
2. **3/8 规则**只处理“未分配且候选含 3/8”的剩余格：这类格必须填完（3 先于 8）。统计：only3 → 3 共 1,967 格、only8 → 8 共 632 格，零反例。
3. **其余剩余格**（候选不含 3/8，包括空候选/自由格）统一收尾为 3 或 8，逐盘混合，不由剩余配额决定。


### 反例（否定“特殊候选格会按规则顺序填入 3/8”）

- 459 张盘、778 个格：这些格候选不含 3/8，战斗配额仍有剩余却变成了事件；位面 2 占 350 盘 / 588 格。
- 典型：2012102（2 个此类格全变 8，战斗配额还剩 5）、2012045（5 个里 3 个变 8）、2012014（5 个里 3 个变 8，40%/60%）、2012065（5 个里 1 个变 8）。

### 特殊候选格（候选不含 3/8）最终比例

- 全库 2,320 个：**战斗 1,004（43.3%）/ 事件 1,316（56.7%）**
- 位面 1：906 个（20.5% / 79.5%）；位面 2：1,414 个（57.9% / 42.1%）；位面 3：0
- 只看“战斗配额还有剩余”的盘：1,694 个（51.4% / 48.6%）

## 数据规模

- 216 个模板（几何、候选、PoolA/PoolB、规则序）
- 1,505 条截图记录（位面 1/2/3 = 682/610/213），命中 81 个模板、1,297 张不同盘面
- 17 种几何：位面 1 6 种、位面 2 10 种、位面 3 1 种（20131 固定盘）
- 图册分组：位面 1 = 30 张（6×5）、位面 2 = 50 张（10×5）、位面 3 = 1 张、其它 5 位数配置 = 20 张（页末）


## 限制

- 识别面向本作“进入位面预览”的 1920×1080 截图（与 1,505 张实测同 UI）；裁切图、其他分辨率或别的界面会识别失败。
- 图册只涵盖位面 1/2/3 与其它 5 位数配置；RogueNous / MapRepo160 的 115 个配置未纳入。
